# BEN 10: MULTIVERSO MOBILE

Protótipo Android de fã, com personagens e transformações originais inspirados no conceito de multiverso e heróis transformáveis. Projeto não oficial, sem afiliação ou endosso dos detentores de Ben 10.

## Protótipo atual
- Seletor de três versões do herói (Clássico, Omniverse e Moderno).
- Arena/cidade 2D estilizada com movimentação por toque.
- Interface de dispositivo de transformação, seleção de formas e botões de ação.
- Aplicativo Android em tela cheia usando WebView.

## Gerar APK
O workflow **Android APK** compila o APK de depuração a cada push para `main`. Abra a aba **Actions**, selecione a execução mais recente e baixe o artefato `ben10-multiverso-debug-apk`. O arquivo APK fica dentro do ZIP.

Este é um protótipo 2D inicial, não o jogo 3D de mundo aberto final.
